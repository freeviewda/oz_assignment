📝 1. 코드 에디터 & 콘솔

JavaScript, HTML 템플릿, CSS 스타일 탭에 코드를 입력하고, 하단 제어 버튼과 타임라인으로 한 줄씩 실행합니다.

🧊 2. 3D 메모리 공간

변수가 생성되면 3D 상자로 표시됩니다. 왼쪽엔 Global · Script · Closure, 오른쪽 상단엔 Local Scope가 자동 배치됩니다.

🌐 3. Live DOM 미리보기

HTML/CSS/JS로 만든 웹페이지가 실시간으로 그려지며, 버튼 클릭 시 연결된 JS 코드를 한 줄씩 추적할 수 있습니다.

💡 화면 크기 조절 팁: 세 영역 사이의 세로 경계선을 좌우로 드래그하면 패널 너비를 자유롭게 조절할 수 있고, 상단의 🧊 3D 메모리 / 🌐 Live DOM 버튼으로 필요한 화면만 골라 크게 볼 수 있습니다.

1분 만에 따라 해보기

STEP 1

예제 열기 또는 코드 작성

처음 접속하면 기본 예제 탭이 열려 있습니다. 상단 📚 스니펫을 누르면 참조/복사, 이벤트 루프, 계산기, 업다운 게임 등 다양한 예제를 바로 열 수 있습니다.

STEP 2

실행 버튼 누르기

🚀 실행 (F5)을 누르면 코드가 한 줄씩 자동 재생됩니다. 재생 속도는 0.3x(천천히)부터 ⚡ 최고속까지 자유롭게 바꿀 수 있습니다.

STEP 3

앞뒤로 시간 여행 디버깅

F10(다음 줄), F9(이전 줄), F8(함수 건너뛰기)나 타임라인 슬라이더를 움직여 원하는 실행 시점으로 마음대로 이동해 보세요.

🔴 중단점(Breakpoint) 기능: 에디터 왼쪽 줄 번호를 클릭하면 빨간 점(🔴)이 찍힙니다. 그다음 ⏩ BP까지 버튼을 누르면 빨간 점이 찍힌 줄까지 한 번에 실행하고 멈춥니다.

🧊 3D 메모리 공간 활용법

✨ 코드 ↔ 상자 호버 연동

  • 에디터의 변수 이름 위에 마우스를 올리면, 3D 메모리 공간에서 해당 변수 상자와 연결된 배열·객체 데이터만 노란색으로 반짝입니다.
  • 마우스 커서 옆에 현재 변수 값이 말풍선으로 바로 표시됩니다.
  • 배열([])이나 객체({})를 다른 변수에 대입하면 주황색 점선 화살표로 같은 메모리를 가리키는 모습을 한눈에 확인할 수 있습니다.

🖐️ 상자 자유롭게 이동 & 정리

  • 상자 1개 이동: 상자를 마우스 왼쪽 버튼으로 드래그
  • 여러 상자 한 번에 이동: 빈 공간을 마우스로 드래그해 파란 네모로 묶은 뒤, 선택된 상자를 드래그 (Ctrl+클릭으로 개별 선택 추가/해제)
  • 스코프 통째 이동: Global Scope, Local Scope 같은 상단 제목 영역을 마우스 왼쪽 버튼으로 드래그
  • 확대/축소 & 원위치: Ctrl + 마우스 휠로 확대/축소, 🧲 정렬 초기화로 원래 배치로 복구
4

🌐 HTML + CSS + JS 웹페이지 실습하기

📄 코드 입력 방법 (2가지 모두 지원!)

  • 방법 A — 탭 나눠 쓰기: 🧱 HTML 템플릿에 HTML, 🎨 CSS 스타일에 CSS, 📜 JavaScript에 JS를 각각 입력하고 🚀 실행 (F5)을 누릅니다.
  • 방법 B — 전체 HTML 한 번에 붙여넣기: <!DOCTYPE html>부터 <style>, <script>까지 들어 있는 전체 HTML 코드를 🧱 HTML 템플릿 탭에 통째로 붙여넣고 🚀 실행 (F5)을 누르면, 앱이 스타일과 스크립트를 자동으로 분리해서 실행합니다. (단, JavaScript 탭이 비어 있을 때 자동 분리됩니다.)
🎞️ 타임트래블 (클릭디버깅) · 기본 모드

버튼 클릭 과정을 한 줄씩 추적

먼저 🚀 실행 (F5)을 한 번 누른 뒤, 우측 Live DOM 화면의 버튼을 클릭하면 연결된 이벤트 함수의 첫 줄에서 자동으로 멈춥니다. F10(Next) / F9(Prev)를 눌러 변수와 화면이 어떻게 바뀌는지 한 단계씩 관찰할 수 있습니다.

⚡ 인터랙티브 모드

일반 브라우저처럼 즉시 실행

우측 Live DOM 패널 상단의 ⚡ 인터랙티브 버튼을 누르면 한 줄 디버깅 없이 일반 웹페이지처럼 클릭·입력 결과가 즉시 화면에 반영됩니다. 우측 상단 ⛶ 크게 또는 🗗 새 창으로 화면을 넓혀 볼 수도 있습니다.

🗂️ 여러 연습장 동시에 쓰기

상단 ➕ 새 탭으로 새 연습장을 만들 수 있고, 탭 제목을 더블클릭하면 원하는 이름으로 바꿀 수 있습니다.

💾 브라우저 자동 저장

작성 중인 탭과 내가 추가한 개인 스니펫은 내 브라우저에 자동 저장됩니다. 같은 브라우저로 다시 접속하면 이전 작업을 그대로 이어서 볼 수 있습니다.

📥 내 PC로 파일 저장 / 열기

💾 저장을 누르면 .js 또는 .jsv.json(HTML/CSS 포함) 파일로 다운로드되고, 📂 열기로 PC의 파일을 바로 불러올 수 있습니다.
