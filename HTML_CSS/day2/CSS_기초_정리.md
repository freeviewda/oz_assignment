# CSS 기초 완벽 정리 가이드

초보자도 한 번에 이해할 수 있도록 **CSS의 핵심 원리부터 실무에서 반드시 알아야 하는 문법과 속성**까지 친절하고 자세하게 정리한 문서입니다.

---

## 1. CSS 란? (Cascading Style Sheets)

### 💡 일상 속 비유로 이해하기
- **HTML**이 건물의 **철골 뼈대와 벽돌**이라면,
- **CSS**는 벽에 바르는 **페인트, 예쁜 조명, 바닥 타일, 인테리어 디자인**입니다.

HTML만 작성하면 흰 배경에 검은 글자만 있는 밋밋한 화면이 되지만, CSS를 입히면 사용자가 보기 편하고 아름다운 웹 사이트로 변신합니다.

### 📌 CSS의 기본 문법 구조
CSS는 **"누구에게(선택자), 어떤 스타일을(속성), 어떻게 바꿀 것인가(속성값)"**를 선언하는 언어입니다.

```css
선택자 (Selector) {
    속성 (Property): 속성값 (Value);
}
```

#### 실제 예시:
```css
h1 {
    color: royalblue;
    font-size: 24px;
}
```
- **선택자 (Selector)**: `h1` (화면의 모든 `<h1>` 태그를 찾아서)
- **선언 블록 (Declaration Block)**: `{ ... }` (중괄호 안에 스타일 규칙들을 작성)
- **속성 (Property)**: `color`, `font-size` (글자 색상, 글자 크기를)
- **속성값 (Value)**: `royalblue`, `24px` (로열블루 색상으로, 24픽셀 크기로 지정)
- **구분자**: 속성과 값 사이에는 콜론(`:`), 규칙의 끝에는 반드시 세미콜론(`;`)을 찍어줍니다.

> **Q. Cascading(계단식/폭포수)이란 무슨 뜻인가요?**  
> 스타일 규칙이 위에서 아래로 물처럼 흐르며 적용되고, 여러 규칙이 충돌할 경우 **우선순위(중요도, 구체성, 작성 순서)**에 따라 최종 스타일이 결정된다는 의미입니다.

## 2. CSS 적용 방식 3가지

CSS를 HTML에 연결하는 방법은 크게 3가지가 있습니다.

### ① Inline CSS (인라인 방식)
HTML 태그 안에 `style` 속성을 직접 적어주는 방식입니다.

```html
<p style="color: red; font-size: 18px;">이 글자는 빨간색입니다.</p>
```
- **장점**: 특정 요소에 빠르게 시험 삼아 스타일을 적용해 볼 때 편합니다.
- **단점**: 스타일이 HTML 코드와 섞여 지저분해지고, 같은 스타일을 여러 곳에 반복해서 써야 하므로 유지보수가 매우 어렵습니다.

---

### ② Internal CSS (내부 스타일 시트)
HTML 문서의 `<head>` 태그 안에 `<style>` 태그를 만들어 스타일을 모아 적는 방식입니다.

```html
<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <title>Internal CSS 예시</title>
    <style>
        h1 {
            color: green;
            text-align: center;
        }
        p {
            font-size: 16px;
        }
    </style>
</head>
<body>
    <h1>내부 스타일 시트</h1>
    <p>본문 내용입니다.</p>
</body>
</html>
```
- **장점**: HTML 파일 하나 안에서 구조와 스타일을 함께 관리할 수 있으며, 해당 페이지의 모든 태그에 스타일을 일괄 적용할 수 있습니다.
- **단점**: 다른 HTML 페이지에서는 이 스타일을 재사용할 수 없습니다.

---

### ③ External CSS (외부 스타일 시트) ⭐ [실무 표준 & 가장 권장!]
별도의 `.css` 파일(예: `style.css`)을 만들어 스타일을 작성하고, HTML 문서의 `<head>` 안에서 `<link>` 태그로 연결하는 방식입니다.

**HTML 파일 (`index.html`):**
```html
<head>
    <!-- 외부 CSS 파일 연결 -->
    <link rel="stylesheet" href="./style.css">
</head>
```

**CSS 파일 (`style.css`):**
```css
body {
    background-color: #f9f9f9;
}
h1 {
    color: darkblue;
}
```
- **장점**: 
  - HTML(구조)과 CSS(디자인)가 완벽히 분리되어 코드가 깔끔해집니다.
  - 하나의 CSS 파일을 수십, 수백 개의 HTML 페이지가 공유할 수 있어 **유지보수와 재사용성**이 극대화됩니다.
  - 브라우저가 CSS 파일을 캐싱(저장)하므로 웹 페이지 로딩 속도도 빨라집니다.

---

### 🏆 3가지 방식의 우선순위 비교
동일한 태그에 서로 다른 스타일이 적용되면 브라우저는 다음 순서로 우선 적용합니다:
$$\text{Inline CSS (가장 높음)} > \text{Internal CSS / External CSS (더 나중에 읽힌 코드)} > \text{브라우저 기본 스타일}$$

## 3. CSS Selector (선택자)

스타일을 적용할 타겟 HTML 요소를 콕 집어 선택하는 방법입니다.

| 선택자 종류 | 문법 기호 | 코드 예시 | 설명 |
| :--- | :---: | :--- | :--- |
| **전체 선택자** | `*` | `* { margin: 0; }` | 페이지의 **모든 요소**를 한꺼번에 선택합니다. (보통 여백 초기화에 사용) |
| **태그(타입) 선택자** | `태그명` | `p { color: gray; }` | 지정한 **모든 해당 태그**를 선택합니다. |
| **클래스 선택자** | `.` | `.highlight { background: yellow; }` | `class="highlight"`를 가진 요소를 선택합니다. **여러 요소에 중복 사용 가능**합니다. |
| **아이디 선택자** | `#` | `#header { height: 60px; }` | `id="header"`를 가진 요소를 선택합니다. **한 페이지에서 유일한 단 1개**만 존재해야 합니다. |

### 많이 쓰이는 결합 선택자 & 가상 클래스 선택자

1. **자손 선택자 (공백)**: 특정 부모 안의 모든 하위 요소
   ```css
   /* div 안에 들어있는 모든 p 태그 */
   div p {
       color: blue;
   }
   ```

2. **자식 선택자 (`>`)**: 특정 부모 바로 밑의 직계 자식 요소만
   ```css
   /* ul 바로 직계 자식인 li 태그만 */
   ul > li {
       list-style: none;
   }
   ```

3. **가상 클래스 선택자 (`:hover`, `:active`, `:focus`)**: 특정 상태일 때 스타일 적용
   ```css
   /* 마우스를 올렸을 때 (:hover) */
   button:hover {
       background-color: dodgerblue;
   }

   /* 링크 밑줄 제거 후 호버 시 밑줄 생기기 */
   a {
       text-decoration: none;
   }
   a:hover {
       text-decoration: underline;
   }
   ```

### 🎯 선택자 우선순위 점수표 (Specificity)
같은 요소에 여러 스타일이 충돌하면 점수가 높은 선택자가 승리합니다!
1. `!important` (예외적인 최고 권한, 남용 금지)
2. **Inline 스타일** (`style="..."`): **1000점**
3. **아이디 선택자** (`#id`): **100점**
4. **클래스/가상클래스 선택자** (`.class`, `:hover`): **10점**
5. **태그 선택자** (`p`, `div`): **1점**
6. **전체 선택자** (`*`): **0점**

## 4. style 핵심 속성 완벽 정복

### a. 텍스트(Text) 관련 속성

글자의 모양, 크기, 정렬, 줄 간격을 조절할 때 사용합니다.

```css
p {
    font-size: 16px;              /* 글자 크기 */
    font-weight: bold;            /* 글자 굵기 (normal, bold, 100~900) */
    color: #333333;               /* 글자 색상 */
    text-align: center;           /* 글자 정렬 (left, center, right, justify) */
    line-height: 1.6;             /* 줄 간격 (가독성을 위한 핵심 속성) */
    text-decoration: none;        /* 밑줄, 취소선 조절 (none, underline) */
    font-family: Arial, sans-serif; /* 글꼴(폰트) 지정 */
}
```

- **`font-size`**:
  - `px`: 고정된 절대 크기 단위 (예: `16px`)
  - `rem`: 최상위(`html`) 기본 글자 크기에 비례하는 상대 단위 (반응형에 유리, 보통 `1rem = 16px`)
- **`font-weight`**:
  - `normal` (400), `bold` (700), 또는 `100` ~ `900` 숫자로 굵기 지정
- **`text-align`**:
  - `left` (기본값, 왼쪽 정렬), `center` (가운데 정렬), `right` (오른쪽 정렬)
- **`text-decoration`**:
  - `<a>` 태그의 기본 파란 밑줄을 없앨 때 `text-decoration: none;`을 자주 사용합니다.

---

### b. Box Model (박스 모델) 완벽 정복 ⭐

웹 브라우저에서 **모든 HTML 요소는 눈에 보이지 않는 사각형 박스(Box)**로 취급됩니다. 이것을 **Box Model**이라고 부릅니다.

#### 📦 박스 모델의 4단계 구조 (안쪽부터 바깥쪽 순서)
```
+-------------------------------------------------------+
|  Margin (바깥쪽 여백 - 다른 요소와의 거리)            |
|   +-----------------------------------------------+   |
|   |  Border (테두리 선)                           |   |
|   |   +---------------------------------------+   |   |
|   |   |  Padding (안쪽 여백 - 내용과 선 사이) |   |   |
|   |   |   +-------------------------------+   |   |   |
|   |   |   |  Content (내용 - 글자나 사진) |   |   |   |
|   |   |   +-------------------------------+   |   |   |
|   |   +---------------------------------------+   |   |
|   +-----------------------------------------------+   |
+-------------------------------------------------------+
```

1. **Content (콘텐츠 영역)**
   - 텍스트나 이미지가 들어가는 실제 알맹이 영역입니다.
   - `width`, `height` 속성으로 가로와 세로 크기를 지정합니다.

2. **Padding (안쪽 여백)**
   - 내용(Content)과 테두리(Border) 사이의 안쪽 빈 공간입니다.
   - 배경색을 지정하면 패딩 영역까지 색이 채워집니다.

3. **Border (테두리)**
   - 패딩 바깥을 감싸는 테두리 선입니다.
   - 선 굵기, 선 종류, 선 색상을 지정합니다.
   ```css
   border: 1px solid #cccccc; /* 굵기: 1px, 종류: 실선, 색상: 회색 */
   ```

4. **Margin (바깥쪽 여백)**
   - 테두리(Border) 바깥의 여백으로, **다른 주변 박스들과의 간격**을 벌릴 때 사용합니다.
   - 배경색이 칠해지지 않는 투명한 공간입니다.

---

### 💡 여백(Margin / Padding) 단축 속성 표기법 (Shorthand)
시계 방향(`위 ➔ 오른쪽 ➔ 아래 ➔ 왼쪽`) 원리만 기억하면 매우 쉽습니다!

```css
/* 1개 값: 상/하/좌/우 모두 동일하게 20px */
padding: 20px;

/* 2개 값: [상/하] [좌/우] */
padding: 10px 20px;

/* 3개 값: [상] [좌/우] [하] */
padding: 10px 20px 30px;

/* 4개 값: [상] [우] [하] [좌] (시계 방향 12시 ➔ 3시 ➔ 6시 ➔ 9시) */
margin: 10px 20px 30px 40px;
```

> **꿀팁: 블록 요소 가운데 정렬하기**  
> 고정 너비가 있는 요소에 `margin: 0 auto;`를 주면 브라우저가 좌우 여백을 자동으로 반반 나눠 가져 화면 중앙에 딱 배치됩니다.

---

### 🚨 초보자가 가장 많이 겪는 혼란: `box-sizing`

#### 기본값: `box-sizing: content-box` (혼란의 원인!)
```css
div {
    box-sizing: content-box;
    width: 100px;
    padding: 20px;
    border: 5px solid black;
}
```
- 브라우저가 계산하는 실제 전체 가로 너비:  
  $$\text{너비(100px)} + \text{좌우 패딩(40px)} + \text{좌우 테두리(10px)} = \mathbf{150px}$$
- **문제점**: 100px 박스를 원했는데 패딩과 테두리를 넣을 때마다 박스가 점점 더 뚱뚱해져서 레이아웃이 깨집니다!

#### 해결책: `box-sizing: border-box` ⭐ [실무 필수]
```css
div {
    box-sizing: border-box;
    width: 100px;
    padding: 20px;
    border: 5px solid black;
}
```
- 브라우저가 계산하는 실제 전체 가로 너비:  
  **무조건 지정한 100px로 고정!**
- 패딩(20px)과 테두리(5px)가 100px 안쪽으로 파고들어가므로 전체 크기가 변하지 않아 레이아웃 계산이 훨씬 직관적이고 편안해집니다.

> **💡 그래서 모든 웹 프로젝트 시작 시 CSS 최상단에 이 코드를 꼭 적어줍니다:**
> ```css
> * {
>     box-sizing: border-box;
>     margin: 0;
>     padding: 0;
> }
> ```

## 5. 한눈에 정리하는 체크리스트

| 질문 | 핵심 요약 |
| :--- | :--- |
| **CSS의 역할은?** | HTML로 만든 웹 페이지의 뼈대에 색상, 글꼴, 레이아웃 등 스타일을 입히는 언어 |
| **가장 추천하는 적용 방식은?** | 별도 파일로 분리하여 `<link>`로 불러오는 **External CSS** 방식 |
| **`.`과 `#`의 차이는?** | `.`은 여러 번 쓸 수 있는 **class**, `#`은 단 하나만 쓰는 **id** |
| **Padding과 Margin의 차이는?** | **Padding**은 테두리 **안쪽** 여백, **Margin**은 테두리 **바깥쪽** 여백 |
| **박스 크기 계산이 자꾸 커질 땐?** | `box-sizing: border-box;`를 적용해 테두리와 패딩을 너비에 포함시키기 |
