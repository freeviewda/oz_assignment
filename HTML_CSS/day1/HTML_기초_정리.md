# HTML 기초 완벽 정리

7개의 실습 파일(`base.html`, `paragraph.html`, `list.html`, `table.html`, `anchor.html`, `image.html`, `form.html`)을 바탕으로, **HTML을 처음 배우는 사람도 쉽게 이해할 수 있도록** 핵심 개념과 태그를 정리한 문서입니다.

---

## 1. HTML 문서의 기본 구조 (`base.html`)

HTML은 웹 페이지의 **뼈대**를 만드는 언어입니다. 모든 HTML 파일은 아래와 같은 기본 틀에서 시작합니다.

```html
<!DOCTYPE html>
<html lang="en">

<!-- 메타 데이터(문서 설정 정보) -->
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My Page</title>
</head>

<!-- 실제 화면에 보이는 부분 -->
<body>
    Hello, HTML
</body>

</html>
```

### 태그별 역할
- `<!DOCTYPE html>` : "이 문서는 최신 HTML5 표준으로 작성되었습니다"라고 브라우저에 알려주는 선언문입니다.
- `<html> ... </html>` : HTML 문서 전체를 감싸는 가장 바깥쪽 태그입니다. (`lang="ko"` 또는 `"en"`으로 주 언어를 표시합니다.)
- `<head> ... </head>` : 화면에는 직접 보이지 않지만, 문서의 설정 정보(메타데이터)를 담는 영역입니다.
  - `<meta charset="UTF-8">` : 한글이 깨지지 않도록 문자 인코딩을 UTF-8로 설정합니다.
  - `<meta name="viewport" ...>` : 모바일 화면에서도 글자나 레이아웃이 적당한 크기로 보이게 맞춰줍니다.
  - `<title>` : 브라우저 상단 탭에 표시되는 문서 제목입니다.
- `<body> ... </body>` : 브라우저 화면에 **실제로 그려지는 모든 내용**을 적는 영역입니다.
- `<!-- 주석 -->` : 개발자가 메모를 남길 때 사용합니다. 화면에는 보이지 않습니다.

## 2. 제목, 문단, 구분선 (`paragraph.html`)

글을 구조적으로 배치할 때 사용하는 가장 기본적인 텍스트 태그입니다.

```html
<!-- 제목 (Heading) -->
<h1>One</h1>
<!-- 문단 (Paragraph) -->
<p>Hello, HTML!</p>

<!-- 가로 구분선 (Horizontal Rule) -->
<hr>

<h2>Two</h2>
<p>Hello, HTML!</p>

<h3>Three</h3>
<p>Hello, HTML!</p>
```

### 태그별 역할
- `<h1>` ~ `<h6>` : **제목(Heading)** 태그입니다. `h1`이 가장 크고 중요한 대제목이며, 숫자가 커질수록(`h2`, `h3` ... `h6`) 작아집니다.
- `<p>` : **문단(Paragraph)** 태그입니다. 하나의 단락을 표현하며, 위아래로 자동 여백이 생깁니다.
- `<hr>` : 주제나 영역을 나눌 때 가로선을 그어주는 태그입니다. 닫는 태그(`</hr>`)가 없는 **빈 태그**입니다.

## 3. 목록 만들기 (`list.html`)

여러 항목을 나열할 때 사용합니다. 순서의 유무에 따라 `<ul>`과 `<ol>`로 나뉩니다.

```html
<!-- 순서가 없는 목록 (Unordered List) -->
<ul>
    <li>Apple</li>
    <li>Banana</li>
    <li>Cherry</li>
</ul>

<!-- 순서가 있는 목록 (Ordered List) -->
<ol>
    <li>첫 번째</li>
    <li>두 번째</li>
</ol>
```

### 태그별 역할
- `<ul>` : **순서 없는 목록**입니다. 각 항목 앞에 점(•) 같은 글머리 기호가 붙습니다.
- `<ol>` : **순서 있는 목록**입니다. 각 항목 앞에 자동으로 번호(`1.`, `2.`, `3.`...)가 붙습니다.
- `<li>` : 목록 안의 **항목 하나하나(List Item)**를 나타냅니다. 반드시 `<ul>` 또는 `<ol>` 안에 넣어 사용합니다.

## 4. 표 만들기 (`table.html`)

데이터를 행(가로)과 열(세로)로 깔끔하게 정리할 때 사용합니다.

```html
<table>
    <!-- 테이블 헤더 (제목 줄) -->
    <thead>
        <tr>
            <th>ID</th>
            <th>이름</th>
            <th>나이</th>
        </tr>
    </thead>
    <!-- 테이블 바디 (실제 데이터) -->
    <tbody>
        <tr>
            <td>1</td>
            <td>alex</td>
            <td>20</td>
        </tr>
        <tr>
            <td>2</td>
            <td>bob</td>
            <td>30</td>
        </tr>
        <tr>
            <td>3</td>
            <td>chris</td>
            <td>40</td>
        </tr>
    </tbody>
</table>
```

### 태그별 역할
- `<table>` : 표 전체를 감싸는 태그입니다.
- `<thead>` : 표의 **머리글(제목 영역)**을 묶습니다.
- `<tbody>` : 표의 **본문(데이터 영역)**을 묶습니다.
- `<tr>` : 표의 **가로 한 줄(Table Row)**을 만듭니다.
- `<th>` : **제목 셀(Table Header)**입니다. 기본으로 글자가 굵고 가운데 정렬됩니다.
- `<td>` : **일반 데이터 셀(Table Data)**입니다.

### 결과 미리보기
| ID | 이름 | 나이 |
| :---: | :---: | :---: |
| 1 | alex | 20 |
| 2 | bob | 30 |
| 3 | chris | 40 |

## 5. 하이퍼링크 (`anchor.html`)

클릭하면 다른 웹 페이지로 이동할 수 있는 링크를 만듭니다.

```html
<a href="https://www.google.com">구글</a>로 이동
```

### 태그와 속성
- `<a>` : **앵커(Anchor)** 태그로, 링크를 생성합니다. 태그 사이의 글자(`구글`)가 클릭 가능한 링크가 됩니다.
- `href` : 클릭했을 때 **이동할 주소(URL)**를 적는 필수 속성입니다.

> 💡 **팁**: `target="_blank"` 속성을 추가하면 현재 창이 아니라 **새 탭**에서 링크가 열립니다.
> ```html
> <a href="https://www.google.com" target="_blank">구글(새 탭)</a>
> ```

## 6. 이미지 넣기 (`image.html`)

웹 페이지에 사진이나 그림을 표시합니다.

```html
<!-- 외부 인터넷 주소(URL)에서 이미지 불러오기 -->
<img src="https://images.unsplash.com/..." width="300" alt="샘플 이미지">

<!-- 같은 폴더에 있는 이미지 파일 불러오기 -->
<img src="pizza.jpg" width="700" alt="피자 사진">
```

### 태그와 속성
- `<img>` : 이미지를 표시하는 태그입니다. 닫는 태그(`</img>`)가 필요 없습니다.
- `src` : 이미지의 **위치(경로)**를 지정합니다.
  - 인터넷 주소(`https://...`)를 적으면 웹에 올라온 이미지를 불러옵니다.
  - 파일 이름(`pizza.jpg`)을 적으면 현재 HTML 파일과 같은 폴더에 있는 이미지를 불러옵니다.
- `width` : 이미지의 가로 너비(px)를 지정합니다. 높이(`height`)를 생략하면 원본 비율에 맞춰 자동으로 조절됩니다.
- `alt` : 이미지가 깨져서 보이지 않을 때 대신 표시되는 **대체 텍스트**입니다. 시각장애인용 화면 읽기 프로그램(스크린 리더)도 이 내용을 읽어주므로, 이미지 설명을 적어두는 것이 좋습니다.

> ⚠️ **주의**: `width="300"`처럼 속성 값 안에는 불필요한 줄바꿈이나 공백을 넣지 않고 한 줄로 적는 것이 안전합니다.

## 7. 입력 폼과 버튼 (`form.html`)

사용자로부터 검색어나 회원가입 정보 등을 입력받아 서버로 전송할 때 사용합니다.

```html
<form action="https://www.google.com/search" method="get">
    <input type="search" name="q" placeholder="검색어 입력">
    <button>입력</button>
</form>
```

### 태그와 속성
- `<form>` : 입력 요소들을 하나로 묶어 서버에 전송하는 영역입니다.
  - `action` : 입력한 데이터를 **어느 주소로 보낼지** 지정합니다.
  - `method="get"` : 데이터를 **URL 주소 뒤에 붙여서** 전송하는 방식입니다. (주로 검색에 사용)
- `<input>` : 사용자가 글자를 입력하는 칸을 만듭니다.
  - `type="search"` : 검색어 입력용 텍스트 상자입니다. (입력 시 오른쪽에 `X` 지우기 버튼이 생깁니다.)
  - `name="q"` : 서버로 전송할 때 붙는 **데이터의 이름(키)**입니다. 구글 검색은 검색어 이름으로 `q`를 사용합니다.
  - `placeholder` : 아무것도 입력하지 않았을 때 칸 안에 흐리게 보이는 안내 문구입니다.
- `<button>` : 클릭할 수 있는 버튼을 만듭니다. `<form>` 안에 있으면 `type="submit"`을 생략해도 **자동으로 전송 버튼**으로 동작합니다.

### 실제 동작 과정
1. 입력 칸에 `고양이`를 입력하고 `입력` 버튼을 누릅니다.
2. 브라우저가 `action` 주소 뒤에 `?name=입력값`을 붙여 `https://www.google.com/search?q=고양이`로 이동합니다.
3. 구글에서 "고양이"를 검색한 결과 화면이 열립니다!

## 8. 한눈에 보는 핵심 태그 요약표

| 분류 | 태그 | 의미 / 역할 | 주요 속성 |
| :--- | :--- | :--- | :--- |
| **구조** | `<html>`, `<head>`, `<body>` | 문서 전체, 설정 정보, 화면 본문 | `lang` |
| **문서 정보** | `<meta>`, `<title>` | 인코딩·화면 설정, 브라우저 탭 제목 | `charset`, `name`, `content` |
| **텍스트** | `<h1>`~`<h6>`, `<p>`, `<hr>` | 제목, 문단, 가로 구분선 | - |
| **목록** | `<ul>`, `<ol>`, `<li>` | 순서 없는 목록, 순서 있는 목록, 항목 | - |
| **표** | `<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>` | 표, 머리글, 본문, 행, 제목 셀, 데이터 셀 | - |
| **링크** | `<a>` | 다른 페이지로 이동하는 링크 | `href`, `target` |
| **이미지** | `<img>` | 사진/그림 표시 | `src`, `width`, `alt` |
| **입력 폼** | `<form>`, `<input>`, `<button>` | 데이터 전송 영역, 입력창, 전송 버튼 | `action`, `method`, `type`, `name`, `placeholder` |
